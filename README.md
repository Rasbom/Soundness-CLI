How to Upload Soundness proof to CLI 

👉 go to https://github.com/codespaces/templates 

👉 select Blank proceed with this line of code

1. sudo apt update && sudo apt upgrade -y

👉 (if you are stuck at 87% press Enter button and press 1 it will proceed)
<img width="1450" height="248" alt="Image" src="https://github.com/user-attachments/assets/c690256e-9519-4014-8697-99b8e0e1c018" />

2. curl -sSL https://raw.githubusercontent.com/soundnesslabs/soundness-layer/main/soundnessup/install | bash

3. curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs/ | sh

4. source ~/.bashrc

5. soundnessup install

6. soundnessup update

7. soundness-cli import-key --name my-key --mnemonic "YOUR SECRET PHRASE"

👉. you can change the key name from my-key to your preffered name
